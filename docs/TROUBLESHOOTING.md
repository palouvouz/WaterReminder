# Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Πιθανή αιτία / Λύση |
|---|---|
| Δεν έρχονται ειδοποιήσεις | Έλεγξε στις ρυθμίσεις του Android ότι οι ειδοποιήσεις της εφαρμογής είναι ενεργές (Android 13+: δώσε την άδεια όταν ζητηθεί). Έλεγξε ότι είσαι συνδεδεμένος: μετά την αποσύνδεση δεν στέλνονται ειδοποιήσεις. |
| Οι ειδοποιήσεις έρχονται με καθυστέρηση | Δώσε άδεια «ακριβών alarms» από το κουμπί στην κύρια οθόνη. Αφαίρεσε την εφαρμογή από τους περιορισμούς μπαταρίας. |
| Σταμάτησαν μετά από επανεκκίνηση | Άνοιξε μία φορά την εφαρμογή. Σε ορισμένες συσκευές η «βελτιστοποίηση μπαταρίας» μπλοκάρει την αυτόματη εκκίνηση. |
| Δεν έρχονται ειδοποιήσεις τις σχολικές ώρες | Είναι σωστό αν είναι ενεργή η λειτουργία μαθητή. Ισχύει Δευτέρα–Παρασκευή. |
| Δεν ακούγεται ήχος ή δεν δονείται | Έλεγξε τον τρόπο ειδοποίησης στις ρυθμίσεις. Το κανάλι της ειδοποίησης μπορεί να έχει αλλαχθεί από τις ρυθμίσεις του Android. Η λειτουργία «Μην ενοχλείτε» το αποκλείει. |
| Δεν έρχονται ειδοποιήσεις μετά την επίτευξη στόχου | Είναι σωστό. Επανέρχονται την επόμενη ημέρα. |
| Το κουμπί Skip δεν εμφανίζεται | Έχεις χρησιμοποιήσει όλα τα skip της ημέρας. |
| Οι ρυθμίσεις μηδενίστηκαν | Συνδέθηκες με διαφορετικό λογαριασμό από τον προηγούμενο στη συσκευή. Οι ρυθμίσεις είναι τοπικές και δεν συγχρονίζονται. |
| Ο κύκλος προόδου δεν εμφανίζεται | Κλείσε και άνοιξε ξανά την εφαρμογή. Έλεγξε ότι υπάρχουν τα `progress.html`, `progress.css` και `progress.js` στον φάκελο `assets`. |
| «Λάθος email ή κωδικός» | Το μήνυμα είναι σκόπιμα κοινό. Έλεγξε και τα δύο. Μετά από 5 αποτυχίες η σύνδεση κλειδώνει προσωρινά. |
| «Αυτός ο τρόπος σύνδεσης δεν είναι ενεργοποιημένος» | Ενεργοποίησε τον πάροχο στο Firebase Console (Authentication → Sign-in method). Για σύνδεσμο email, ενεργοποίησε και το «Email link». |
| «Η σύνδεση με Google δεν έχει ρυθμιστεί ακόμα» | Λείπει το `default_web_client_id`. Ενεργοποίησε τον πάροχο Google, πρόσθεσε τα SHA-1 και SHA-256, κατέβασε ξανά το `google-services.json` και κάνε Gradle Sync. |
| «Δεν βρέθηκε λογαριασμός Google» | Πρόσθεσε λογαριασμό Google στη συσκευή. Ο emulator πρέπει να έχει Google Play. |
| Η σύνδεση με Google αποτυγχάνει με σφάλμα 10 ή 12500 | Τα SHA-1/SHA-256 του κλειδιού που υπέγραψε το APK δεν είναι καταχωρισμένα στο Firebase (debug και release έχουν διαφορετικά). |
| Ο σύνδεσμος email ανοίγει στον browser και όχι στην εφαρμογή | Τα SHA-256 δεν έχουν προστεθεί στο Firebase ή το `google-services.json` είναι παλιό. Έλεγξε με `adb shell pm get-app-links com.example.waterreminder`. Μπορείς να τον ανοίξεις και χειροκίνητα με «Άνοιγμα με» → Water Reminder. |
| «Ο σύνδεσμος έχει λήξει» ή «δεν είναι έγκυρος» | Ο σύνδεσμος ισχύει για περιορισμένο χρόνο και μία φορά. Ζήτησε νέο. |
| Δεν φτάνει το email (σύνδεσμος, επαναφορά, επιβεβαίωση) | Έλεγξε τα ανεπιθύμητα. Υπάρχει αναμονή 60 δευτερολέπτων μεταξύ αποστολών. |
| «Πάρα πολλές προσπάθειες» | Το Firebase περιόρισε τις αιτήσεις. Περίμενε λίγα λεπτά. |
| Σφάλμα στη σύνδεση | Έλεγξε το internet και ότι ο κωδικός πληροί τους κανόνες του project. |
| Η εφαρμογή κρασάρει στην εκκίνηση | Συνήθως λείπει ή είναι λάθος το `google-services.json`. Το package name πρέπει να είναι `com.example.waterreminder`. |
| Σφάλματα build | Δες το `docs/BUILD_APK.md`. |
| Το `git push` απέρριψε το `google-services.json` | Σωστά. Είναι στο `.gitignore` και δεν πρέπει να ανεβαίνει στο GitHub. |
